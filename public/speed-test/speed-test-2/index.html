三、如何提升视频播放流畅度与缓解缓冲

  1. 开启分流策略组：在 Clash 策略组与分流配置教程 中，将 YouTube 与 Netflix 域名指定走香港或日本高速节点。
  2. 优化本地 DNS 解析：配置 Fake-IP 模式以防止本地 DNS 污染导致视频 CDNs 识别错误，详情参考 Clash DNS 防污染教程。
